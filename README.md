# 🗓️ Daily Task Planner

A clean, responsive, and interactive **Daily Task Planner** built with HTML, CSS, and JavaScript. This simple yet powerful web app lets users add daily tasks with specific times and dates, and manage them with a modern, elegant UI.

![screenshot](https://via.placeholder.com/900x400?text=Daily+Task+Planner+Screenshot) <!-- Replace with an actual screenshot if available -->

---

## ✨ Features

- ✅ Add tasks with date and time
- 🕒 Timestamps display for clear scheduling
- 🧼 Clean and minimalistic UI
- 🗑️ One-click task deletion
- 📱 Responsive design for desktop and mobile
- 🔥 Animated task entries with hover effects

---

## 🔧 Built With

- **HTML5** – Structure
- **CSS3** – Styling & Animations (Glassmorphism-inspired design)
- **Vanilla JavaScript** – Task logic, timestamp handling, and DOM manipulation
